# 标准识图与计量规则

> 最后更新：2026-11-05
> 标准口径版本：quote-app-36791a0，属于原报价器业务口径，不代表行业统一收费标准。

## 页与实体

- 产品立面、正视、内部结构图作为主体依据；单一台面、榻榻米、会议桌的产品俯视图也可用。
- 纯户型/房间/厨房沿墙布局只定位，不直接计量。封面、目录、说明、效果图、材料及五金编码表不生成安装数量。
- 混合页的平面只作参考，立面逐个识别；不能因为含平面图而跳过整页。
- 柜体以独立完整外轮廓为主体。内部上/下柜、门板、玻璃格、抽屉格不另算一个柜体；有间隔、独立位置/外轮廓才拆分。
- 外观与内部图按空间、柜号、位置、外轮廓、尺寸一一配对，内部图优先取量。相同标题/尺寸不足以证明同一柜。不同 A/B/C 立面通常是不同墙面。
- 修订版和旧版不叠加；适用版本不明时列冲突，不自行选较大数。
- 每项保存来源、区域、尺寸原文、公式、主视图及配件父柜。缺依据的候选项单列待确认。

## 默认计量表

| 类型 | 单位与公式（尺寸 mm） | 取量依据 |
|---|---|---|
| cabinet 普通柜体 | 高≥1000：长×高÷1,000,000 平米；高<1000：长÷1000 米，每个独立柜不足1米按1米 | 正面整体外轮廓，不是板材展开面积 |
| cabinet 餐边柜 | 始终按整体长×高÷1,000,000 平米 | 连续上下柜合一，局部“吊柜/地柜”不改为延米 |
| wall_panel 墙板 | 长×高÷1,000,000 平米 | 可核验覆盖尺寸；洞口扣除用自定义口径 |
| tatami 榻榻米 | 长×深÷1,000,000 平米 | 本体俯视，不用立面高度替代深度 |
| countertop 台面 | 长÷1000 米 | 本体俯视实际长度 |
| wall_cabinet 厨房吊柜/镜柜 | 长÷1000 米 | 各自正面水平外轮廓 |
| base_cabinet 厨房地柜/浴室柜 | 长÷1000 米 | 各自正面水平外轮廓 |
| desk 书台/书桌/会议桌 | 桌面总长÷1000 米 | 会议桌俯视/仰视/结构图均可，不默认按张 |
| light_strip 灯带 | 独立安装位置数，条 | 明确“灯带/加灯/加灯带/预留灯” |
| drawer 抽屉 | 明确标注数，个 | 柜内逐处清点，不计五金编码表 |
| pull_basket / dish_basket / seasoning_basket | 个 | 拉篮/碗篮/调味篮分别识别，不归入抽屉 |
| door 木门 | 扇 | 独立房门、木门，不包含柜门/门板 |

尺寸保留原始精度，最终数量三位小数；每行金额按数量×单价四舍五入两位后加总。实际几何量、最低计量值、重复倍数分开记录；保底不是测得尺寸。

## 易错场景

1. 已确认本体边界高为950+1434时，餐边柜3674×2384÷1,000,000=8.758816→8.759平米，不能拆成两个延米柜。此算例不表示所有柜体都应扣封板：若另有2434总高，需核对50mm属于计量外轮廓、独立封板还是图纸矛盾；未明确就列疑点，不默认扣除/计入。连接侧板仅在连接关系、尺寸明确时加算并说明是否已包含，不经验补面积或重复相加。
2. 厨房 L/U：A正向20+305+900+350+50=1625，B正向50+480+900+475+50=1955，合计3.580米。端部600明确为相邻柜深度投影时排除；不能看到600就扣，不确定段待复核。
3. 浴室柜与上方独立镜柜两行，分别取水平长度，不共用上下总高、台盆深度或推测宽度。
4. 抽屉类包括“抽屉、屉、木抽、内抽、裤抽、抽盒、抽斗、抽格、抽拉盒、键盘抽”。7处“450托底抽”是7个；“拉手/拉条/免拉手/抽屉拉手”不等于抽屉；编码表“抽屉1/抽屉2”不代表2个。
5. 6个层格各写“加灯”是6条。只有虚线或扇形光芒符号时列候选、待复核；尺寸线、中心线、隐藏轮廓不算灯带。
6. 柜门外观单页只作参考，不新增主体；柜门不算木门；拉直器不单独计量，也不转成其他配件。
7. 会议桌×2、每件5500mm→11.000米；倍数只乘一次。“5500×1200”是尺寸，不是重复数量。配件先记每个父柜数量，再应用父柜倍数，不能重复继承。
8. 双层床按两层实际床面核算；同尺寸且证据明确时面积×2。又有多套时分开记录层数和套数，先核实，不能盲目覆盖或相乘。
9. 榻榻米1955×1210÷1,000,000=2.36555→2.366平米；立面1090总高不是深度。
10. 单位不明、长深互换、必需尺寸缺失、尺寸链冲突、配件数量异常、来源不明均待复核。置信度<0.55不能自动纳入，高置信度也不能替代证据。

v1.3将这些复核条件写入结构化evidence检查，见data-contract.md。抽屉只有明确标注或用户确认才属于已确认量；可辨认的外观候选仍须建配件行、记录父柜/候选数/截图并标visual_candidate，按v1.4默认暂计进入报价，不能因没有文字标注直接漏掉。候选数也看不清时留待补数量，不猜0或强填数字。所有柜体的相邻侧深投影都要结合关联视图核对归属，不能把厨房算例的扣减数字照搬到衣柜。缺少证据时先留疑点，不为了使两模型总量一致而调整。

## v1.4 报价展示口径（用户指定）

待复核是证据状态，不再是从报价明细移除的条件。已有当前选用尺寸/数量时按同一标准公式暂计，并纳入报价汇总；冲突备选、转角重复风险等留在备注。缺少必需尺寸不猜值，重复实体不双算，仍保留行和未计量原因。原始证据与确认门槛不降低，不能把暂计称为准确确认量。

## v1.4.3 跨模型取量一致性检查

- 对同一实体采用内部结构图所标本体外轮廓；总外框、本体、门板净尺寸、相邻柜侧投影和安装标高分别识别。结构图与其他视图冲突时保留各读数、当前采用值及理由，暂计并标待复核；不能因为算例、最大数或前次模型结果而选值。底离地标高不能当柜高。
- 净尺寸和外框尺寸不同本身不证明矛盾，也不能据此把所有柜一律待复核；关键是计量边界能否明确。封板归属或标高含义不清才列具体疑点。
- 转角柜交叉核对相邻方向和定位图，已含在另一柜的侧深投影不重复计。户型图可用于核验转角归属，但不得作为报价缩略图。证据不足则保留重复风险与备选量，不默认全宽准确。
- 上下有空区不等于两个独立柜，先核验贯通侧板/背板及实际独立外轮廓。拆合不明时列备选方案及影响，当前暂计方案唯一，不把两套方案同时汇总。
- 五类配件逐项检查中“没有文字标注”不等于“无候选”；已看到抽面却不建候选行属于覆盖遗漏。反过来，候选数不是最终确认数，不能为对齐另一个模型擅自确认。
- 模型对账按文件/页码/空间/产品边界匹配，不能直接按Q编号对齐；先查实体拆合、分类、计量尺寸、配件候选，最后查公式。未统一疑点采用值前，总量不同不表示乘法出错。
