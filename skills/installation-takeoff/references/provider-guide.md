# 服务商简单使用说明

> 最后更新：2026-11-05
> v1.3.0；常规流程用自然语言，智能体执行本地命令。

## 第一次只要一句话

在WorkBuddy导入v1.3.0技能，选择实际支持图片的模型，上传PDF或给出本地路径，然后说：

> 用 installation-takeoff 技能算这套图的安装量。按标准规则，价格先空着，输出带缩略图的Excel。先预检并确认能看清一页尺寸线，每批3–4页保存；只放大疑点，不重复识整套图。

本轮可优先验证客户端实际可用的DeepSeek V4.1 Flash，思考保持默认或均衡。先做一页图片检查；官方API支持图片不代表当前WorkBuddy路由一定支持，详见[模型与效率复测](models.md)。首次需Python 3.11+和本地依赖，后续复用；CAD优先从原设计软件导出清晰PDF。

智能体每批只简报已处理页数、确定项和疑点，详细依据保存到项目。不会要求你反复手抄JSON，也不会为了补价重新看整套图。

## 常用说法

| 你想做什么 | 直接这样说 |
|---|---|
| 接着完成 | “从这个项目继续，只处理下一批未完成页。” |
| 找项目 | “找Q003，告诉我现在的尺寸、来源和待复核原因。” |
| 修正尺寸 | “Q003宽度是2390，不是2397，依据内部结构图第5页。” |
| 人工补尺寸 | “Q008总高我确认2500mm，记录成我的确认，不冒充图纸识别。” |
| 改本单规则 | “本项目普通矮柜按实际米数，不足1米不保底。” |
| 保存常用口径 | “把这套服务商口径保存成‘本店标准’，以后我说应用时再使用。” |
| 应用已存口径 | “这单应用已保存的‘本店标准’，先列出影响哪些行。” |
| 补价格 | “柜体投影35元/平米，裤抽20元/个，普通抽屉包含在柜体费里。” |
| 查疑点 | “Q009转角可能重复，只核对相关原图，列出扣除依据。” |
| 重导Excel | “用当前台账重新导Excel，不重新识图。” |
| 接续手改表 | “读这份最新Excel及同名manifest，只接续实际改过的价格和备注；冲突给我看。” |

更改前后要能看到原值→新值、原因和影响。例如普通矮柜800mm取消保底，1.000米→0.800米。餐边柜有独立类型口径，不能只看高度就套普通矮柜规则。常用口径仅在明确要求保存时进入profile，明确要求应用时才影响新项目。

## 疑点怎么确认

打开本地复核卡，逐项看原图缩略图、尺寸和问题；填好后下载反馈JSON，交回智能体接续。这个下载只保存你的原话，不会直接确认或改写尺寸；待复核可计算项已默认暂计。智能体需核对对应ID、证据与计量字段，再按明确确认写入新批次。

Excel“报价明细”S列也可填写原话。接续时会保存为“人工输入待处理”并保持可见；写了“已确认”不等于自动通过。文字与当前台账有不同修改时先解决冲突，不替你挑选一份。

## 结果怎么检查

先核对一条链：表中可见编号→原图和来源页→尺寸轴与完整边界→规则→数量。缩略图用于定位，小字应打开原页或裁图。

再检查每个房间/立面是否齐全、同一柜是否重复；餐边柜上下是否重复拆算；转角是否把相邻柜侧面计入正面；封板与尺寸链是否一致；抽屉、灯带等是否逐类确认覆盖。仅凭外观识别的配件候选保留待复核状态，按记录候选数暂计。页面都处理过也不代表产品和配件已经查全。

未报价留空，免费填0。待复核项显示“待复核·已暂计”并按当前资料进入数量汇总；合计包含已填价的暂计项，覆盖或复核未完成时仍是草稿。

## 文件怎么拿、怎么保留

点击真实生成的xlsx文件，聊天表格不算Excel交付。两页签为报价明细、报价汇总。左右手Logo、蓝色标题、蓝字单价格和最后一行金额合计保持不变；明细N列显示稳定编号。汇总D列填分类价，明细I列可填单行价，L列含疑点提示和可编辑备注，S列填写人工复核意见。浅绿色为依据齐全，浅橙色为待复核；汇总备注列逐项显示来源空间/产品、尺寸(mm)、数量及单位，并以公式关联明细。明细表头可核对PDF总页数、参与计算页数及页码。

发客户可以只发Excel，缩略图已嵌入。自己保存整个项目文件夹和最新xlsx、同名.manifest.json；v1.3工作簿及基准绑定项目UUID、源文件指纹和修订，重名项目不能混用。旧表没改过的单价和备注不会覆盖更新的台账；实际改过的内容成功接续后会写回状态，下一次普通导出仍保留。

数量、尺寸、金额公式、合计、标签、资料或行结构被手改时，会提示具体单元格，需先逐项核对；排序/插入/删除不能保证自动恢复图片归属。旧v1.2工作簿没有UUID，先保留旧表逐行对照，再把确认内容存为新批次，不能自动猜所属项目。

换机器前使用项目归档；本版归档必须包含源快照，缺失或哈希变化会报错，先修复来源再归档。已有旧项目先迁移/恢复，保留旧状态和旧表，不重新初始化覆盖。具体命令由智能体按[固定步骤](runtime.md)执行。

## 本轮复测走四步

1. **原图**：同一套脱敏图，标准口径、价格空白，拿到带缩略图Excel；核对一条原图到数量的完整依据及产品/配件覆盖。
2. **规则**：说“本单普通矮柜按实际米数”，检查800mm由1.000变0.800，餐边柜和其他行保持各自口径。
3. **价格**：口述一组分类价，再手改一条明细价和备注，接续导出后普通重导一次，确认0价、空价和修改都保存。
4. **Excel**：核对图片对应ID、汇总金额和末行单一合计；在明细S列人工复核意见写一句原话，确认能接续保留且仍需核验。记录真实总时间/积分。

首次安装耗时单独记录。平台没有tokens或积分明细就填未知。合成测试通过说明工具链可运行；目标WorkBuddy/模型的识图速度、消耗和误差仍以本次真实复测为准。
