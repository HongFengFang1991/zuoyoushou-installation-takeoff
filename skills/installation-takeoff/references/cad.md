# CAD 资料接入

> 最后更新：2026-11-04

v1.3 提供 CAD 接入工作流，不捆绑通用 DWG 解析器。DWG/DXF 自动转换依赖本地工具；缺工具时请求带完整标注的 PDF，继续标准识图。

| 输入 | 路径 | 完成条件 |
|---|---|---|
| CAD 导出的 PDF/图片 | 标准流程 | 尺寸、视图、布局来源清楚 |
| DXF | 本地 DXF 工具提取实体/标注并渲染；否则导出 PDF | 必须查看渲染图，不能只列 TEXT 就声称识图完成 |
| DWG | 已有 CAD 软件导出 PDF；或本地转换器转 DXF 后解析渲染 | 保留原文件/布局和转换记录，抽查尺寸及文字 |
| 3D 实体/代理对象/丢外参 | 请求完整工程包或二维尺寸图 | 补齐前标记未覆盖 |

在既有授权内使用本地工具，另存转换文件。不自动上传第三方转换站，不静默安装未知插件；缺工具时说明缺口，不让模型猜二进制。

核对顺序：

1. 登记模型空间、布局、外参和版本；布局视口与模型往往同一实体，不能双计。模型里的多个图框分别登记。
2. 核实绘图/插入/图块局部单位及缩放、旋转、镜像、阵列。无单位时至少用两条明确尺寸校验比例；冲突则确认，不默认毫米。
3. 对照 DIMENSION 测量值、文字替代值和几何长度；人工改过的标注可能与几何冲突。已标实际尺寸不再乘打印比例。
4. 处理嵌套图块和 INSERT 实例后关联柜体；不按 BLOCK 定义数当柜数，不按 LINE 条数当板件数。
5. 核实关闭/冻结/不可打印图层的出图范围，避免漏实体或计入辅助线。
6. 缺字体、SHX、外参、嵌入图片、代理实体时登记缺口。轮廓不能证明抽屉/灯带，仍需业务证据。
7. 依据含原文件、模型/布局、区域/柜号；有解析结果时可补实体 handle、图层、块位置。转换页映射回原布局。
8. 几何与图像冲突列待复核，不自动取大数。CAD 取尺寸不能替代主体去重或业务口径。

工具参考：[ezdxf 外参](https://ezdxf.readthedocs.io/en/stable/xref.html)、[图块说明](https://ezdxf.readthedocs.io/en/stable/tutorials/blocks.html)、[ODA 转换器](https://www.opendesign.com/guestfiles/oda_file_converter)、[Autodesk DWG TrueView](https://help.autodesk.com/view/TRUEVIEW/2026/ENU/?guid=GUID-B603523F-7CFB-47C9-AC3C-B4F9FE0D8D21)。版本兼容和许可按厂商要求，本包未捆绑这些工具。
